Network security monitoring has good tools and no cloud-native home. Trawl is a
Kubernetes operator that treats Zeek and Suricata as first-class workloads. It
was built for Talos Linux, where the host is immutable and there is no SSH and
no package manager, so a sensor cannot be installed on a node at all: everything
is a pod, and everything that changes is a resource.

It is alpha. The API is `v1alpha1` and will change.

## What you declare

<CardGrid>
	<Card title="NetworkTap" icon="magnifier">
		An interface to watch and which analyzers to run on it. A mirror source
		gets one pod; a node source gets a DaemonSet that rolls one node at a
		time, so an update never blinds the whole cluster.
	</Card>
	<Card title="CapturePolicy" icon="approve-check">
		A trigger armed against a tap, with bounded capture behavior. It defaults
		to disarmed, because creating a policy is not the same act as switching
		it on.
	</Card>
	<Card title="CaptureJob" icon="document">
		One bounded packet capture and its verified artifact. Retrieving it is
		authorized per request and written to the ledger before the bytes move.
	</Card>
	<Card title="PortMirror" icon="setting">
		A mirror session on a switch, so a tap has something to observe. Its
		status reports what the device says, never what was asked for.
	</Card>
</CardGrid>

## Three properties that drove the design

<CardGrid>
	<Card title="Passive, and fail-open for traffic" icon="heart">
		Trawl must never affect the packets it watches. No component has a
		transmit path, and every failure mode degrades monitoring rather than the
		network.
	</Card>
	<Card title="Fail-closed for privileged operations" icon="seti:lock">
		A capture whose authorization could not be durably committed does not
		happen, and a download the ledger did not hear about is not served. The
		ledger is a gate, not a log.
	</Card>
	<Card title="Status is a claim, not an echo" icon="star">
		A tap reporting Active means traffic is being analyzed right now. An
		external witness watches the event worker, so a dead worker cannot leave
		every policy claiming coverage it is not providing.
	</Card>
</CardGrid>
